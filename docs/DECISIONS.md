| 23  | PROMPT-03 | **Invitation creation security & policy (binding):** Invitation tokens are generated from 256 bits of cryptographically secure randomness, encoded URL-safe (base64url), and persisted ONLY as a deterministic SHA-256 hex hash (`tokenHash`) — the raw token is returned from the creation operation exactly once, never persisted, never logged, and never included in errors/analytics; lookups are hash-only. Invitations expire 7 days after creation (`expiresAt = createdAt + TTL`, centralized as `INVITATION_EXPIRY_DAYS`). Expired, revoked, and accepted invitations never block a new invitation.
