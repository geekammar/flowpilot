## Deployment Steps (condensed)

1. Neon database ready → `pnpm db:deploy` (desktop).
2. `pnpm release` → private GitHub repo `flowpilot` pushed.
3. Vercel → Add New Project → Import `flowpilot` → name it (this fixes the
   URL used in step 4).
4. Settings → Environment Variables → add the four above (Production +
   Preview) → Deploy.
5. Validate: `https://<app>.vercel.app/api/health` → `{"status":"ok",…}`;
   sign in with demo credentials (after `pnpm db:seed` if using demo data);
   check RTL rendering + PWA install on Android.
6. Redeploy loop from now on: `pnpm verify` → commit → push → Vercel builds
   → check `/api/health` (bump `package.json` version per release so health
   reports it).
