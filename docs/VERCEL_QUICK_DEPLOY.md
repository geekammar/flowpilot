# FlowPilot — Vercel Quick Deploy (< 5 minutes)

> The fast path from clone to a shareable URL. Detail/troubleshooting:
> `VERCEL_DEPLOYMENT.md` · Full env reference: `ENVIRONMENT_VARIABLES.md`.

## Prerequisites (once, ~2 min)

- **Neon PostgreSQL** — free project at [neon.tech](https://neon.tech) → copy
  the connection string (`Project → Connect`, keep `?sslmode=require`).
- **Vercel account** — free Hobby plan is enough ([vercel.com](https://vercel.com)).
- **Node ≥ 20 + pnpm** — or run `bash scripts/bootstrap.sh` (Windows:
  `bootstrap.ps1`, Android: `bootstrap-termux.sh`).

## Deploy (one command)

```bash
pnpm install && pnpm run setup     # deps + .env.local (random auth secret)
# ↓ edit .env.local (see table), then:
pnpm deploy                        # gates → deploy → prints the URL
```

`.env.local` values (the deploy gate validates all of them):

| Variable              | Value                                            |
| --------------------- | ------------------------------------------------ |
| `DATABASE_URL`        | `postgresql://…@…neon.tech/db?sslmode=require`   |
| `BETTER_AUTH_SECRET`  | already generated by `pnpm run setup`            |
| `BETTER_AUTH_URL`     | `https://<your-app>.vercel.app` (see note below) |
| `NEXT_PUBLIC_APP_URL` | same as `BETTER_AUTH_URL`                        |
| `DEMO_MODE` _(opt.)_  | `"true"` → demo data seeded before every deploy  |

> **First deploy chicken-and-egg:** the URL is only known after deploying.
> Easiest fix: pick the project name first (Vercel names the app for you if
> you `vercel link` / import with that name — URL = `https://<name>.vercel.app`)
> and set the two URL variables to it **before** deploying. Alternatively
> deploy once, then set the URLs in Vercel → Settings → Environment Variables
> (Production **and** Preview) and redeploy.

`pnpm deploy` runs the full gate first (`pnpm deploy:check`: environment,
database connection, Prisma, auth config, build) — if it aborts, every issue
is printed with its exact fix. The same four variables must also exist in
**Vercel → Project → Settings → Environment Variables** (Production + Preview)
or the Vercel build fails.

## First-time Vercel setup (first deploy only)

```bash
pnpm dlx vercel@latest login     # browser login (once per machine)
pnpm dlx vercel@latest link      # connect this folder to the project
```

(Or skip the CLI: push the repo to GitHub — `pnpm release` — and import it in
Vercel; every push to `main` then redeploys automatically.)

## Verify (30 seconds)

1. `https://<your-app>.vercel.app/api/health` →
   `{"status":"ok","deploymentReady":true,"database":"connected",…}`
2. Sign in at `/sign-in` — `admin@flowpilot.app` / `Admin@1234` (with
   `DEMO_MODE=true` or after `pnpm db:seed` + `pnpm db:deploy` for the schema).
3. Share the URL — demo package: `docs/CLIENT_DEMO.md`.

## Commands recap

| Command               | What it does                                                  |
| --------------------- | ------------------------------------------------------------- |
| `pnpm deploy:check`   | Readiness gate only → READY / NOT READY with fixes            |
| `pnpm deploy`         | Gate → **production** deploy → URL (share this one)           |
| `pnpm deploy:preview` | Gate → preview deploy → URL (internal use; auth may not work) |

Stuck? `docs/TROUBLESHOOTING.md` + `VERCEL_DEPLOYMENT.md` Section 6.
